# Authored suite examples

Apache-2.0, Lattice contributors. These small files are generated from the same versioned recipes as the full local suites. They contain procedural references and canonical responses for inspecting schema/scorer contracts; they are public illustrative fixtures, not secret evaluation data.

Full suite recipes, seed, stratified partitions, distributions and limitations are described in [datasets.md](../../../docs/datasets.md). Do not use these displayed canonical responses as model prompts during quality evaluation. Each JSON file includes an early sample of records and whole-suite template counts; the sample is not a representative benchmark.
