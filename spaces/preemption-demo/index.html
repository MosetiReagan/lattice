Head-of-Line Blocking Solution

Instant Chat Replies for Local LLMs

Local inference engines (llama.cpp, Ollama, vLLM CPU) queue requests strictly FIFO. When a 500-token document summary runs, urgent user chats stall for 10+ seconds. Lattice preempts heavy tasks instantly, serves the chat in milliseconds, and seamlessly resumes background work.

Measured Empirical Scaling Laws

Real hardware benchmark data tested on Qwen2.5-0.5B-Instruct-F16 with llama.cpp backend on CPU.

Proven Hardware Results
Queue Wait Scaling Law
5.1x → 12.8x

Queue wait speedup scales linearly with background token length. While FIFO delay grows proportionally with document size, Lattice queue wait stays constant at ~12ms.

TTFT (Time-To-First-Token)
4.8x Faster

At 160 contention tokens, TTFT drops from 3,736 ms (FIFO) down to 772 ms (Lattice). At 512 tokens, users get instant first tokens in under a second instead of 11+ seconds.

Get Started with Lattice in 60 Seconds

1. Install from PyPI
pip install lattice-inference
2. One-Command Setup
lattice init
3. Serve with Preemption
lattice serve --model model.gguf --preset chat
4. Request with Priority
curl http://localhost:8000/v1/chat/completions \
  -H "X-Lattice-Priority: 1" \
  -d '{"messages": [{"role":"user","content":"Hi"}]}'
