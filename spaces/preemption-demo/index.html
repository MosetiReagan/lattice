Responsive Local LLM Serving Under Contention

Lattice is an OpenAI-compatible local inference server powered by llama.cpp. It brings operating system scheduling principles to LLM execution—combining token-level preemption, continuous multi-slot batching, KV prefix reuse, and memory safety guardrails to eliminate Head-of-Line queue stalls on CPU hardware.

⚡

Preemptive Priority Scheduling

Interactive chat requests bypass queue congestion. Active background generation yields cooperatively at token boundaries (<150ms), reducing queue wait by 5.1x to 12.8x without task cancellation.

🔄

Continuous Multi-Slot Batching

Native multi-slot orchestration (--native-slots 2..8) concurrent requests concurrently without head-of-line blocking, dynamically saturating available CPU instruction pipelines.

🧠

KV-Cache Prefix Reuse

Preserves computed Key-Value attention tensors across request suspensions and shared system prompts. Resumed tasks bypass prompt re-evaluation, achieving zero-waste compute continuity.

🛡️

Host-Reserve Memory Guard

Real-time hardware telemetry via /proc/meminfo (Linux) and vm_stat (macOS) enforces strict RAM reserves, preventing kernel OOM kills under burst workloads.

📈

Prometheus Telemetry & Tracing

Native /metrics endpoint exposing queue latencies, preemption counts, slot saturation, and structured JSON event logs for production enterprise observability.

🔌

OpenAI & Universal GGUF Support

Drop-in replacement for OpenAI SDKs, Open WebUI, Cursor, and Continue. Supports Llama 3, Qwen 2.5, DeepSeek, Mistral, Gemma 2, and Phi 3 architectures out-of-the-box.

Empirical Parity Validated
Queue Wait Scaling Law
O(1) vs O(N_bg)

In sequential scheduling, queue latency scales linearly with background token volume ($T \propto N_{bg}$). Under Lattice preemption, interactive queue latency remains constant at ~12ms regardless of batch length.

Deployment & Integration

Lattice provides drop-in compatibility with the OpenAI API protocol.

1. PyPI Installation 
pip install lattice-inference

Published release with zero compiled C++ dependencies.

2. System Calibration 
lattice init

Detects AVX-512/NEON vector extensions and provisions backend.

3. Start Server 
lattice serve --preset chat

Serves OpenAI endpoints with preemption and continuous batching.
