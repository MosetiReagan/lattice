# Quality evaluation contract

Implemented: exact output-token comparison hooks, static-scored public task fixtures, corpus perplexity tooling and raw execution records. No representative quality preservation claim is currently justified. The first 22 public smoke tasks scored 11/22 at FP16; strict formatting is intentionally part of the task, so Markdown or extra prose fails exact/JSON rubrics. Original labels and failures are retained. The AST coding rubric does not execute generated code and is not a coding benchmark.

Frozen same-representation baselines and candidate runs must use identical tokenization, model/checkpoint and sampling. Greedy cache/speculation experiments compare complete token-ID sequences; failures cannot be excluded from latency averages without also reporting them. Quantized or routed models require separate quality analysis and must not be selected automatically from a small favorable task subset.

The original external corpus study uses WikiText-2 raw test, pinned Salesforce/wikitext revision b08601e04326c79dfdd32d625aee71d232d685c3. `scripts/prepare_wikitext.py` records raw Parquet/text hashes and attribution; install pyarrow separately to run it. Its CC-BY-SA/GFDL dataset terms do not become the code license. Text remains external to source distributions. Perplexity is measured with pinned llama-perplexity, explicit context/chunks and the same text/tokenizer; arbitrary cross-tokenizer comparisons are prohibited. A four-chunk repeated self-authored corpus pilot is instrumentation evidence only, not this external benchmark.

Proposed automatic approximate-path acceptance remains <=2% relative perplexity increase and <=1 percentage-point task-score loss with sufficient confidence. These criteria are not relaxed because this VM is small or a model scores poorly. Until held-out representative tasks and confidence bounds support a path, the controller must preserve model/precision constraints and mark it unqualified. Greedy equivalence on a finite prompt set establishes only that tested scope, not universal bitwise equivalence or stochastic distribution preservation.

Expanded intake-v1 data and scoring protocols are documented in [datasets.md](datasets.md), with separate measured outcomes in [dataset_results.md](dataset_results.md). The catalog adds nine external source families and four authored suites; code execution and official IFEval scoring remain deferred. Frozen per-task subsets, actual tokenization/context exclusions and conservative paired uncertainty prevent data volume from being mistaken for automatic quality qualification. The old 22-task and 32-chunk results stay preserved.
